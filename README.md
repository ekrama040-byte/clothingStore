# 🛍️ Ekram Studio – Modern E-Commerce Storefront

A lightning-fast, fully responsive modern e-commerce web application built with Next.js (App Router), Tailwind CSS v4, and Zustand, powered by the Fake Store API.

---

## ✨ Features

- Product Catalog Grid: Responsive product browsing fetching real-time items from the Fake Store API.
- Dynamic Product Cards: Smooth image zoom animations on hover and dynamic buttons that toggle between *"Add to Cart"* and *"Remove from Cart"*.
- Global Cart Management: State handled seamlessly with Zustand (with persistence middleware so your cart stays saved on refresh).
- Interactive Quantity Controls: Increment and decrement item quantities directly in the cart, with automatic removal if the quantity drops to zero (0).
- Live Cart Badge Counter: Real-time item count badge in the navigation bar.
- Boutique UI/UX: Designed with a sleek indigo/violet gradient aesthetic, soft shadows, and responsive layout.

---

## 🛠️ Tech Stack

- Framework: [Next.js 15 (App Router)](https://nextjs.org/)
- Styling: [Tailwind CSS v4](https://tailwindcss.com/)
- State Management: [Zustand](https://github.com/pmndrs/zustand)
- Icons: [Lucide React](https://lucide.dev/)
- Data Source: [Fake Store API](https://fakestoreapi.com/)
